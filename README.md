# E-Commerce Sales Analytics Dashboard

## Project Overview
This project is a multi-page interactive Power BI dashboard developed to analyze sales performance, customer behavior, product profitability, and return trends using business intelligence techniques and DAX measures.

The dashboard helps identify key business insights related to revenue generation, customer contribution, regional sales performance, product profitability, and loss-making products.

---

# Dashboard Pages

## 1. Executive Overview Dashboard
This dashboard provides a high-level overview of business performance using key KPIs and interactive visualizations.

### Key Features
- Total Sales KPI
- Total Orders KPI
- Total Profit KPI
- Profit Margin Analysis
- Monthly Sales Trend
- Regional Sales Performance
- Top Selling Products
- Interactive Slicers

### Business Insights
- Identified top-performing regions.
- Tracked monthly sales growth trends.
- Analyzed category-wise profit contribution.
- Identified highest-selling products.

---

## 2. Customer Analytics Dashboard
This dashboard focuses on customer segmentation and profitability analysis.

### Key Features
- Top Customers by Revenue
- Top Customers by Profit
- Revenue Contribution by Segment
- Orders by Customer Segment
- Customer KPIs
- Interactive Filters

### Business Insights
- Consumer segment contributed the highest revenue share.
- Identified high-value customers.
- Analyzed customer profitability patterns.
- Compared order behavior across customer segments.

---

## 3. Product & Returns Analytics Dashboard
This dashboard analyzes return trends, revenue leakage, and product profitability.

### Key Features
- Return Rate Analysis
- Revenue Loss by Category
- Product Profitability
- Top Loss-Making Products
- Profit by Sub-Category
- Interactive Product Filters

### Business Insights
- Furniture category showed highest return rate.
- Certain products generated continuous losses.
- Identified revenue leakage trends.
- Compared profitability across sub-categories.
